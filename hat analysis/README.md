# Hat Analysis

## Standard run
```bat
run_hat_analysis.bat
```

## PVGIS hourly run (Marseille + Cairo)
```bat
run_hat_pvgis_hourly.bat
```

Outputs (PVGIS mode):
- `hat_pvgis_hourly_report.html`
- `hat_hourly_marseille.csv`
- `hat_hourly_cairo.csv`

The hourly report includes LaTeX equations, monthly totals, and average benefit by hour-of-day.
